How this is organised

Each market follows the same eight-module arc — industry foundation → forcing functions → the core regulation → the asset-level regime → the wider regulatory stack → market sizing & buyers → competitive landscape → opportunity synthesis — so the two can be read in parallel. The modules are deliberately written for a strong analyst with no prior domain knowledge, without dumbing down. Figures still to be confirmed against primary sources are marked VERIFY; items confirmed from primary text are marked CONFIRMED. Every module can be read on screen or downloaded as a PDF in the same styling.

A living knowledge base — modules update as primary sources are ingested and the regulatory picture evolves. Built as a static site; works offline once loaded.
